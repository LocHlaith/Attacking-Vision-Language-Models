        +-- baseline
        |       |
        |       v
        |   experiment.record_originals()

        |
        +-- attack / all-continuous
        |       |
        |       v
        |   experiment.run_batch()

        |       |
        |       v

        |       |
        |       v

        |
        +-- text

                生成文字模板，求解 0-1 选择模型，保存文字扰动结果

二、数据准备流程

datasets/*.png
    |
    v
model.load_context()
    1. load_raw_image(): resize 到 256，中心裁剪为 224 x 224
    2. normalize(): 使用 ImageNet 均值和方差标准化
    3. load_model(): 读取 models/mobilenet_v2-b0353104.pth
    4. resolve_reference_class(): 若提供 reference_labels.json，则覆盖原类别
    |
    v
ImageModelContext
    提供 logits()、loss()、decision()，供所有算法共用

说明：ImageModelContext 是连续扰动与文字扰动的公共上下文。算法层不直接处理文件路径，而是通过该上下文访问原图张量、模型、原类别和决策函数。

三、连续扰动工作流

experiment.run_batch()
    |
    v
attacks.run_attack(context, algorithm, backend, parameters, settings)
    |
    +-- analytic_first_order
    |       一阶 Lagrange 满意解，直接使用 loss 梯度并投影到二范数球面
    |
    +-- second_order_kkt
    |       二阶 KKT 近似，使用 Hessian-vector product 与手写线性共轭梯度
    |
    +-- weighted_*
    |       objectives.weighted_sum()
    |       |
    |       +-- backend = manual:
    |       |       solvers.manual.steepest_descent()
    |       |       solvers.manual.levenberg_marquardt_newton()
    |       |       solvers.manual.dfp_change_scale()
    |       |       solvers.manual.nonlinear_conjugate_gradient()
    |       |
    |       +-- backend = efficient:
    |               solvers.efficient.library_quasi_newton()
    |
    +-- projected_gradient
    |       objectives.negative_loss() + solvers.manual.projected_gradient()
    |       每步由 project_l2_ball() 保持二范数约束
    |
    +-- external_point / external_point_softplus
    |       objectives.loss_threshold_violation() 或 Softplus 光滑违反量
    |       solvers.manual.external_point_method()
    |       内层求解器按 backend 选择手写最速下降或高效拟 Newton
    |
    +-- dual_loss
    |       approximate_primal_dual() 对 loss 阈值模型做近似原-对偶迭代
    |
    +-- toilet_tissue
            objectives.target_margin() 指向第 1000 类 toilet tissue
            approximate_primal_dual() 求定向分类间隔满意解

连续扰动的输出在 outputs/<algorithm>/<backend>/ 下。每张图保存一个子目录，包含 attacked.png 与 perturbation.png；整批实验另保存 results.csv。

四、文字扰动工作流

text_attack.run_text_batch()
    |
    v
candidate_templates()
    枚举字体大小、顶部/中部/底部位置、旋转角度
    |
    v
render_text_template()
    将默认文字“张天羽”渲染为 224 x 224 的 0-1 mask
    并用 solvers.graph.connected_components() 拆分笔画连通分量
    |
    v
对每张图片和每个模板计算 true_margin()
    |
    +-- text_method = reverse_greedy
    |       reverse_greedy_pruning()
    |       从完整文字开始，按线性化收益由小到大尝试删除像素
    |       删除前检查保留比例、根节点和连通性
    |
    +-- text_method = linearized_milp
            linearized_then_prune()
            |
            +-- backend = manual:
            |       manual_linearized_selection()
            |       手写满意解过程，逐点删除低收益像素
            |
            +-- backend = efficient:
                    efficient_linearized_milp()
                    使用 scipy.optimize.milp 求局部 0-1 线性化模型
                    连通性由网络流约束表达
            |
            v
            reverse_greedy_pruning()
            在线性化解基础上继续剪枝，减小文字扰动面积

文字扰动的图约束由 solvers/graph.py 支撑：

four_neighbours()          生成上下左右四邻域
connected_components()     手写 BFS，识别文字笔画分量
is_connected()             快速连通性检验
ford_fulkerson()           手写增广链最大流
network_flow_connected()   用最大流验证单根连通条件

文字扰动输出在 outputs/text_<method>/<backend>/ 下。除 attacked.png 与 perturbation.png 外，还会保存 mask.png 表示最终选择的文字像素。

五、手写后端与高效后端关系

后端         位置                                               用途                 说明
manual       avlm_or/solvers/manual.py, avlm_or/solvers/graph.py  展示运筹学求解过程   手写线搜索、共轭方向、DFP、外点罚函数、最大流等
efficient    avlm_or/solvers/efficient.py, text_attack.efficient_linearized_milp()  加速实验运行   与手写后端共用模型、目标函数、输入数据和输出规范

六、结果记录流程

AttackOutcome 或 TextAttackResult
    |
    v
torch.clamp(raw_image + perturbation, 0, 1)
    |
    +-- context.decision()                 记录攻击后模型决策
    +-- io.save_attack_images()            保存攻击图和扰动强度图
    +-- io.save_tensor_image(mask.png)     仅文字攻击保存
    +-- io.write_csv(results.csv)          写入统一字段

CSV 字段由 io.CSV_COLUMNS 统一管理，包含图像名、算法、后端、原类别、攻击后类别、决策函数值、阈值、扰动二范数、文字面积、成功状态、耗时、迭代次数和终止信息。

七、常用运行命令

记录四张原图的原始预测：
python -m avlm_or.run baseline

运行单个连续扰动算法：
python -m avlm_or.run attack --algorithm weighted_dfp --backend manual --max-iterations 30

运行全部连续扰动算法：
python -m avlm_or.run all-continuous --backend manual

运行文字反向贪心剪枝：
python -m avlm_or.run text --text-method reverse_greedy --backend manual --max-checks 200

运行文字线性化 0-1 模型的高效后端：
python -m avlm_or.run text --text-method linearized_milp --backend efficient
